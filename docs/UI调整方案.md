# Mac 素材工作台界面调整

用户已选择并要求继续实施此前推荐方向：参考 Spacedrive 的紧凑素材工作台，以及 InvokeAI 的画面与操作面板布局。只参考视觉和布局，不复制上游代码，不新增前端依赖。

## 设计与边界

- 左侧：项目切换、对话图片组、选中导出状态和手动配组。
- 中间：当前组 A/B 大图、原图与修复图切换，底部按时间排列的候选帧。先选 A/B，再点击候选帧替换，禁止两侧使用同一帧。
- 右侧：当前组提示词、模型配组理由、局部修复入口、移除操作。
- 顶部：视频名、分析范围、扫描/分析按钮、保存和导出。底部保留任务状态。
- 深色中性背景、蓝色操作强调，减少装饰卡片，媒体优先。
- 保留现有 Python/pywebview 桥接与 SQLite 数据；不增加即梦、发布或 Windows 功能。

## 实施步骤

1. 在 `tests/test_ui.py` 加入换图与切组保存的行为回归，先运行确认缺失行为；重排 `dialogue_tool/ui/index.html` 的布局、CSS 和交互。保留保存竞态修复及过期图片请求隔离。
2. 全量 pytest、JavaScript 语法检查；在 Mac 原生窗口检查切组、换图、提示词保存、原图切换、修复框选和小窗口布局。更新 README 与实施记录。保留所有现有项目、图片和导出。

界面采用原有单页内嵌资源，以保持 Mac 本地 HTML 加载与桥接兼容。候选帧分页，避免一次载入整部电影全部缩略图。
