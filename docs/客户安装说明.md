# 客户安装说明

当前提供源码验证版，尚无 Windows 安装 EXE、便携包或经过 Windows 11 真机验收的版本。Mac `.app` 为依赖开发目录的启动壳，不能复制给 Windows 客户安装。仓库公开和源码测试通过，均不代表 Windows 客户安装验收完成。

## 下载

在仓库首页点 Code → Download ZIP，解压到有写入权限的固定目录。也可使用 Git 克隆仓库。不要把 Release 中的 `review-evidence` 测试材料包当作安装包。

## Mac 已验证的源码启动方式

先准备 Python 3.11、FFmpeg / FFprobe 和可用的 Codex CLI；账号由使用者本人登录。进入解压目录执行：

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -e '.[desktop,repair]'
.venv/bin/python -m dialogue_tool doctor
.venv/bin/python -m dialogue_tool desktop
```

`doctor` 检查程序路径、登录及本地修复模型，不提交生成任务。第一次真正点击“开始拆解”会使用 Codex 账号额度。LaMa 模型需要另外按 README 配置；模型缺失时不能执行修复。

## Windows 11 源码验证入口（未实机验证）

以下是给部署人员或其他 AI 继续适配时使用的源码命令，当前不能承诺在客户电脑直接成功。需要 Python 3.11 x64、FFmpeg / FFprobe、可用的 Codex 可执行程序及 WebView2 Runtime。PowerShell 进入解压目录后：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[desktop,repair]'
.\.venv\Scripts\python.exe -m dialogue_tool doctor
.\.venv\Scripts\python.exe -m dialogue_tool desktop
```

不需要激活虚拟环境或修改 PowerShell 全局执行策略。检测不到程序时，在项目根目录新建 `settings.local.json`，填写本机实际的 Codex、FFmpeg、FFprobe 可执行文件路径及模型路径，例如：

```json
{
  "codex": "C:/Tools/codex/codex.exe",
  "ffmpeg": "C:/Tools/ffmpeg/bin/ffmpeg.exe",
  "ffprobe": "C:/Tools/ffmpeg/bin/ffprobe.exe",
  "model": "C:/Models/big-lama.pt"
}
```

示例路径不会自动安装软件，请替换为实际位置。不要在配置中写入账号令牌。Windows 上还需验证依赖安装、Codex 子进程调用、进程锁、中文路径、原生窗口、CPU 修复、导出和任务恢复；这些通过后才能交付 Windows 安装版。

## 当前功能范围

导入本地视频 → 对话截图配组 → 人工检查 → 可选局部修复 → 按组导出图片和提示词。即梦生成、自动发布及账号矩阵均未接入。长片全量对话识别尚未验收，详见仓库 `review/` 的实测材料。
