# 客户下载与启动说明

仓库现已公开。当前 Windows 版本提供 Python 环境安装脚本与启动脚本，尚无独立 EXE 安装包。Mac `.app` 仍依赖开发目录，不能复制给 Windows 客户安装。

## Windows 11 客户

1. 在仓库首页点 Code → Download ZIP，解压到固定目录。
2. 按 [Windows 11 无独显安装与验收](Windows11无独显安装与验收.md) 准备 Python 3.11、FFmpeg、Codex 等本机工具，并由客户本人完成登录。
3. 在解压目录打开 PowerShell，执行本地环境安装：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup_windows.ps1
```

4. 双击 `start_windows.bat` 启动。脚本默认只安装主流程所需依赖，不安装 PyTorch/CUDA；LaMa CPU 修复按需另行配置。

Windows 自动化冒烟检查与客户真机验收分别记录，不能将前者当作实际窗口操作、截图效果、修复或付费生成已验收。

## Mac 源码启动

准备 Python 3.11、FFmpeg / FFprobe 与可用的 Codex CLI 后，在解压目录执行：

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -e '.[desktop]'
.venv/bin/python -m dialogue_tool doctor
.venv/bin/python -m dialogue_tool desktop
```

如需修复，再配置 README 中的可选依赖和 LaMa 模型。登录凭据及个人设置不随源码分发。

## 测试材料

`review/` 及 `review-evidence` Release 是旧版历史核查材料，非安装包。其长片只完成镜头扫描和部分 AI 批次，未完成全片对话组验收。远端后来已有拆组与生成等更新，旧材料不能充当更新版的真实效果验证。源码运行、截图准确性和生成计费均需分别检查。
