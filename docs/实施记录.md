# Mac 先跑通再兼容 Windows

## 已批准范围

单机桌面工具，按钮后台调用本机 Codex。先在 Mac ARM64 验证客户真实样例：两图分析、LaMa 修复、两图加提示词提交即梦、下载及 FFmpeg 整理。成功后再实现完整视频分析及界面，Mac 验收后再适配 Windows 11 x64。

同一连续场景同两人只保留一组图片，不辨识实际说话人。每组两张参考图加一个提示词生成一条视频。保留原素材、修复图、模型输出与导出，任务受理后不得因查询失败重复付费提交。

## 实施顺序

1. 独立环境、有效 Codex 路径、项目内即梦 CLI。
2. 最小样例验证入口、任务持久化及防重复提交测试。
3. 客户样例真实验证并记录耗时和结果。
4. 核心链路通过后才推进视频扫描、配组、完整桌面界面。
5. Mac 实际验收后才推进 Windows 构建及真机测试。
