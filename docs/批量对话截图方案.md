## 识别与长片约束

1. 本地逐帧检测镜头，只保存候选；Codex 分批理解，记录对话时间范围和人物描述。
2. 跨批次去重分时间区间、限制单次输入数量，只合并明确重复的同段同人物组合，不进行一次性全片图片合并。
3. 每组再检查不同人物、场景、正反打关系和清晰度，在同镜头候选中改善选帧；缺少独立视角、多人无法确定或模型拒绝确认时进入待确认，不默认勾选导出。
4. 保存成功的各阶段模型结果，失败后复用已完成步骤。最终准备完整尺寸原图，保留源片时间和识别报告。
5. 不承诺任意影片完全准确；验证报告分开列出抽帧技术检查、视觉配组人工核对、漏配和长片实际验证情况。
